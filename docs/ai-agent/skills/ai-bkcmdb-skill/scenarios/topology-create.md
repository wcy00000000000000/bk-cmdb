# 场景：topology_create（创建集群/模块/模板化拓扑）

在蓝鲸配置平台（bk-cmdb）中执行集群与模块拓扑创建。该场景是写操作场景，必须先预览、再确认、后执行、再验证。能力通过 bk-cmdb 的 `open_` 系列工具实现（MCP server 注册名以环境为准，按工具名定位）。

## 适用场景

用户意图属于以下任一类型时使用本场景：

- **仅创建集群（非模板）**：在业务拓扑下新建 set。
- **在已有集群下创建模块**：在指定 set 下新建一个或多个 module。
- **按集群模板创建集群**：创建 set 并由系统自动创建模板关联模块。

## 不适用场景

- 主机资源操作：主机分配、主机转移、主机纳管。
- 非拓扑创建写操作：属性批量修改、删除拓扑、跨业务迁移。
- 与 bk-cmdb 拓扑无关的资源申请流程（如 CLB、机器申请）。

## 安全规则

- 任意写调用前必须先输出预览并获得用户明确回复「确认创建」。
- 重复确认可能导致重复拓扑；对状态未知写操作重试前必须提示重复风险。
- MCP 返回错误或验证未命中时按失败处理，禁止臆断成功。
- 模板创建部分失败时不自动补偿，需汇总失败项并询问用户下一步。
- 预览、日志与总结中不得暴露凭证、token、ticket。

## 查询与创建流程

1. **判定操作类型**
   - 创建集群（非模板）
   - 在指定集群下创建模块
   - 按模板创建集群

2. **解析必要 ID**
   - 已给 `bk_biz_id` 直接使用；仅给业务名时用 `open_search_business` 解析。
   - 业务名命中多个候选时要求用户选择，不按顺序猜测。
   - 按集群名建模块时用 `open_search_set` 解析 `bk_set_id`。
   - 按模板名创建时用 `open_list_set_template` 解析 `set_template_id`。
   - 创建集群时 `bk_parent_id` 需要用户填写，缺少父节点 ID 时先澄清，不发起写调用。

3. **读取当前状态并识别冲突**
   - 创建集群前可用 `open_search_set` 检查同名集群。
   - 创建模块前可用 `open_search_module` 检查目标集群下同名模块。
   - 模板创建时可用 `open_list_set_template_related_service_template` 预览自动生成模块结构。
   - 若集群名含高风险字符（如 `:`），提前提示名称校验失败风险。

4. **输出预览并等待确认**
   - 明确操作类型、业务、父节点、集群、模块、模板、关键参数、将调用的写工具。
   - 明确声明不包含主机分配、主机转移、资源申请。
   - 明确提醒重复确认可能创建重复拓扑。

5. **仅在确认后执行写操作**
   - 创建集群：`open_create_set`，必传 `bk_set_name` + `bk_parent_id`。
   - 创建模块：`open_create_module`，必传 `bk_module_name` + `bk_parent_id`（必须等于 `bk_set_id`）。
   - 模板创建集群：`open_create_set` + `set_template_id`。系统会自动创建模板关联模块，不再调用 `open_create_module` 或 `open_sync_set_template_to_set`。
   - 批量创建模块时按顺序逐个调用并记录每项结果。

6. **验证并返回结果**
   - 用 `open_find_set_batch` / `open_find_module_batch`（或 `open_search_set` / `open_search_module`）按 ID 或名称验证新节点已落库，并确认名称与归属（模块须在目标集群下）。
   - 结果展示拓扑路径时，用已知业务名 + 验证得到的集群名/模块名本地拼接为 `业务名 / 集群名 / 模块名`

## 预览模板


```markdown
将执行 bk-cmdb 拓扑创建预览：
- 操作：创建集群 / 创建模块 / 按模板创建集群
- 业务：<bk_biz_id> <business_name>
- 父节点：<bk_parent_id>
- 集群：<bk_set_id> <bk_set_name>
- 模块：<module_names>
- 模板：<set_template_id> <template_name>
- 参数：<params>
- 写工具：<open_create_set/open_create_module>
- 不需要：主机分配、主机转移、资源申请

确认后才会调用写接口。请明确回复“确认创建”继续。
```

## 完成标准

- 创建集群成功时可返回或解析到 `bk_set_id`，并可通过验证接口查到。
- 创建模块成功时可返回或解析到 `bk_module_id`，并可在目标集群下查询到。
- 模板创建后可查询到新集群及其自动生成模块结构摘要。

## 失败处理

- **业务不存在**：要求补充有效 `bk_biz_id` 或准确业务名。
- **业务/集群匹配多项**：要求用户明确选择。
- **名称冲突**：展示冲突并询问继续、改名或停止。
- **必填 ID 缺失**：缺少 `bk_biz_id`、`bk_set_id` 或 `bk_parent_id` 时停止写调用，补齐后重新预览与确认。
- **`bk_parent_id` 参数无效（create_module）**：应将 `bk_parent_id` 设为 `bk_set_id`，重新预览并确认。
- **`bk_set_name` 参数校验失败**：提示非法字符风险，要求用户改名后重试。
- **工具返回失败**：按 MCP 返回值原样反馈并停止写操作。
- **批量部分失败**：汇总成功/失败项；无新预览和确认前不自动重试。
